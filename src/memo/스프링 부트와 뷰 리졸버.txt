스프링 부트는 서버를 뛰울 때, InternalResourceViewResolver(JSP 리소스 등에 사용)라는 뷰 리졸버를 자동 등록한다.
-> InternalResourceViewResolver : application.properties에 등록한 spring.mvc.view.prefix, spring.mvc.view.suffix 설정 정보를 보고 동작한다. 
InternalResource : JSP의 forward()처럼 클라이언트를 거치지 않고 서버 내부끼리 호출하여 리소스를 찾아서 반환할 때 사용한다.




BeanNameViewResolver 사용 예시
-> 빈 이름으로 뷰를 찾아서 반환

1.엑셀 파일 생성 빈(추후에 수동 등록)
public class ExcelView extends AbstractView {

    public ExcelView() {
        setContentType(
            "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet"
        );
    }

    @Override
    protected void renderMergedOutputModel(
            Map<String, Object> model,
            HttpServletRequest request,
            HttpServletResponse response
    ) throws Exception {

        // 1. 엑셀 파일 생성
        Workbook workbook = new XSSFWorkbook();

        // 2. 시트 생성
        Sheet sheet = workbook.createSheet("회원 목록");

        // 도중 생략

        // 7. HTTP 응답 헤더 설정
        response.setContentType(getContentType());
        response.setHeader(
            "Content-Disposition",
            "attachment; filename=\"members.xlsx\""
        );

        // 8. 엑셀 파일을 HTTP 응답으로 전송
        workbook.write(response.getOutputStream());

        workbook.close();
    }
}

2. 스프링 부트 수동 등록
-> 엑셀 파일 생성 빈 등록(빈 이름 : excelView)
@Configuration
public class ExcelConfig {

    @Bean("excelView")
    public View excelView() {
        return new ExcelView();
    }
}

3. 컨트롤러 호출
@Controller
public class ExcelController {

    @GetMapping("/excel")
    public String downloadExcel(Model model) {

        List<Map<String, Object>> members = List.of(
            Map.of("id", 1, "name", "Kim", "email", "kim@test.com"),
            Map.of("id", 2, "name", "Lee", "email", "lee@test.com")
        );

        model.addAttribute("members", members);

        return "excelView";
    }
-> 이 시점에 model에 들어간 값을 베이스로 엑셀 파일이 생성돼 클라이언트에 반환이 된다.
이때 뷰 리졸버는 return "excelView"을 보고 뷰 리졸버 리스트 중에 스프링 빈 이름이 "excelView"인 빈을 찾아서 실행!
